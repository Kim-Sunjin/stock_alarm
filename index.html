스마트폰 홈 화면에 웹앱(PWA) 설치 & 알림 가이드

앱스토어 심사 없이 아이폰·갤럭시 바탕화면에 전용 앱 아이콘을 만들고 푸시 알림을 받는 방법

1 웹앱 파일 다운로드 및 10초 무료 웹 주소(HTTPS) 만들기

스마트폰의 웹 푸시 알림(Web Push API)과 홈 화면 앱 설치 기능은 보안 정책상 https://로 시작하는 개인 웹 주소에서 작동합니다. 우측 버튼으로 파일을 받은 뒤 아래 무료 사이트에 마우스로 끌어다 놓으면(Drag & Drop) 10초 만에 평생 무료 개인 주소가 생성됩니다.

방법 A: Netlify Drop (가장 빠름)
app.netlify.com/drop 접속 후 다운로드한 HTML 파일이 든 폴더를 드래그하면 즉시 https://나만의주소.netlify.app 발급
방법 B: GitHub Pages / Vercel
파일 이름을 index.html로 저장해 GitHub 저장소에 올리면 무료 HTTPS 모바일 웹앱 주소가 즉시 활성화됨
2 내 스마트폰 홈 화면에 전용 앱으로 설치하기
🍎 아이폰(iOS 16.4 이상) 홈 화면 웹앱 설치 및 알림 허용 순서:
  1. 아이폰 기본 브라우저인 Safari(사파리)로 배포한 웹앱 주소에 접속합니다.
  2. 화면 하단 중앙의 [공유 버튼 (네모 위 화살표 ↑)]을 터치합니다.
  3. 메뉴를 아래로 스크롤하여 [홈 화면에 추가]를 누르고 우측 상단 [추가]를 누릅니다.
  4. 바탕화면에 생성된 'AlphaPulse' 앱 아이콘을 눌러 실행하면 상·하단 주소창이 없는 100% 전체화면 네이티브 앱으로 열립니다.
  5. 앱 내 [알림 설정 & 내역] → [브라우저 푸시 권한 확인] 버튼을 눌러 아이폰 알림 권한을 '허용'하면 아이폰 잠금화면과 알림센터로 알림이 울립니다!
🤖 갤럭시/안드로이드(Chrome · 삼성 인터넷) 설치 및 알림 허용 순서:
  1. 스마트폰 Chrome(크롬) 또는 삼성 인터넷으로 웹앱 주소에 접속합니다.
  2. 우측 상단 [점 3개 메뉴(⋮)](삼성 인터넷은 우측 하단 줄 3개)를 누릅니다.
  3. [홈 화면에 추가] 또는 [앱 설치]를 선택하면 바탕화면에 전용 앱 아이콘이 설치됩니다.
  4. 설치된 앱을 실행한 뒤 [브라우저 푸시 권한 확인] 버튼을 눌러 알림 권한을 허용하거나 아래의 즉시 설치/테스트 버튼을 클릭하세요.
3 모바일 웹앱 자체 알림(Web Notification) vs 24시간 백그라운드 푸시(ntfy)

• 홈 화면 웹앱 자체 알림: 홈 화면에 추가한 앱이 실행 중이거나 백그라운드 대기 중일 때 OS 알림창으로 즉시 표시됩니다.
• 앱을 완전히 종료했을 때도 받으려면?: [알림 설정 & 내역] 탭의 ntfy 또는 텔레그램 연동을 함께 켜두시면, 스마트폰에서 웹앱을 닫아두어도 24시간 빠짐없이 잠금화면 푸시를 받으실 수 있습니다.
